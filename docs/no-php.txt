  [ 找不到 PHP ]

  這台電腦上找不到 php.exe，三個解法擇一即可。


  解法 1 —— 用公司現有的 PHP（最快，不用下載）

    公司現有系統本來就在跑 PHP，找出它的安裝位置：
      常見於  C:\xampp\php\
      或到 IIS 管理員的「FastCGI 設定」裡看完整路徑

    把那整個資料夾複製到本專案底下，並改名為 php
    完成後路徑會長這樣：  本專案\php\php.exe

    再按兩下 start.bat 就會自動找到它。


  解法 2 —— 下載免安裝版（需要一台有網路的電腦）

    https://windows.php.net/downloads/releases/archives/
    下載  php-7.2.24-nts-Win32-VC15-x64.zip
    （本專案就是在 7.2.24 上實測過的版本）

    解壓到本專案底下的 php 資料夾，
    一樣會變成  本專案\php\php.exe


  解法 3 —— 不跑測試伺服器，直接放進公司現有的 Apache / IIS

    這才是正式的跑法，作法見  docs\START.md 的「情境二」。
